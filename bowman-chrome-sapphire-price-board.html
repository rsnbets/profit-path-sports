One autograph per box

Sapphire runs 8 packs a box with 3 exclusive Sapphire parallels and one Chrome autograph. A 10-box case is therefore ten autographs spread across 45 autograph subjects — so most spots in a case break see none. Auto count is what separates a good spot from a dead one.

Every base card is a parallel

In the Sapphire configuration the base Sapphire parallel falls 1:1 — every card is one. The chase sits above it: Yellow 1:14, Gold 1:21, White 1:34, Orange 1:41, Black 1:102, Red 1:203, Papradascha 1:1,011. A plain Sapphire base is the floor, not the hit.

Set the breaker total

Add up every spot the breaker is selling and type it in — the board rescales to it. For randoms, bid against share rather than the headline name: the hyped prospect's spot routinely goes for several times what the card count justifies.

Shares are card counts from the official Topps checklist, weighted base 1 / insert 3 / auto 25. These are not adjusted for prospect hype. 270 cards across 6 sets: 200 base and Chrome Prospects, 25 image variations and Hidden Gems, 45 autographs. Checklist and odds via Checklist Insider.
